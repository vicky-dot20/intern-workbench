# API Browser

**Stack:** JavaScript, HTTP, and testing

**Product brief:** Build a searchable, resilient interface over a public or local JSON API with loading, empty, and error states.

Start with an initialization Issue covering package configuration, folder structure, environment setup, `.env.example`, linting, formatting, testing, Git workflow, README, run command, and build command. Then create milestone-scoped Issues with acceptance criteria. Deliver through small PRs and include accessibility, security, failure-state, documentation, and test evidence appropriate to the level. No real credentials or production data are permitted.
