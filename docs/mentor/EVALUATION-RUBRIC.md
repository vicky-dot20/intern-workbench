# Mentor Evaluation Rubric

Rate evidence across technical ability, problem solving, code quality, Git workflow, testing, debugging, communication, documentation, responsible AI use, code review, and independence.

| Rating | Observable behavior |
|---|---|
| Needs Significant Guidance | Cannot yet reproduce the problem or complete the workflow safely; explanations do not match the submitted work. |
| Developing | Completes bounded work with prompts; misses edge cases or needs help choosing validation. |
| Competent | Independently delivers scoped work, tests it, explains tradeoffs, and responds well to review. |
| Strong | Anticipates risks, improves plans with evidence, reviews others constructively, and needs little procedural support. |
| Developer Ready | Reliably clarifies ambiguous work, navigates unfamiliar code, balances tradeoffs, communicates risk, and owns delivery through review. |

Use concrete PRs, incident notes, reviews, and explanations as evidence. Reassess at milestones; do not average scores mechanically or grade by speed/task count. Record one strength, one growth area, and the next task chosen to test it.
