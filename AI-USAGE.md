# Responsible AI Usage

AI assistance is allowed. Secret use, unverified output, and code the intern cannot explain are not acceptable. This repository does not detect or estimate AI authorship.

Every meaningful PR must state whether AI was used, tools, purpose, what it helped with, what the intern implemented, what changed from the output, verification performed, and whether the intern can explain the result.

The intern remains accountable for licenses, security, privacy, correctness, tests, and repository policy. Never paste secrets, private customer data, proprietary source, or production logs into an unapproved tool. Treat generated code and citations as untrusted until verified.

Mentors should ask the intern to explain a decision, modify the solution under a changed requirement, diagnose an introduced failure, and identify an AI assumption that required verification. Evaluation measures understanding, not guesses about authorship.
