# Contributing

Contributions may improve a task, project, workflow, mentor practice, documentation, or propose a future track. Open an Issue describing the learner problem first for material changes. Keep pull requests focused and include validation evidence.

For tasks, follow [TASK-AUTHORING-GUIDE.md](TASK-AUTHORING-GUIDE.md). For security issues, follow [SECURITY.md](SECURITY.md) rather than opening a public vulnerability report. Contributors must follow [CODE-OF-CONDUCT.md](CODE-OF-CONDUCT.md), certify they may contribute the work, and disclose meaningful AI assistance in the PR template.

Run `npm install` and `npm run validate`. Do not commit secrets, generated dependencies, private company information, placeholder production content, or broken links.
